# WeddingCards

## Getting Started

### 1. Environment Setup
- Manage Node.js versions using **nvm**: https://github.com/nvm-sh/nvm  
- Install Node.js: `nvm install 22`
- Install Git for source code management: https://git-scm.com/downloads
### 2. Clone the Project from GitHub
```bash
git clone https://github.com/dzokha/WeddingCards.git
cd WeddingCards
```
### 3. Install Dependencies 
```bash
npm install
```
### 4. Configure Environment Variables

Create a .env.development file in the project root directory and add the following content:
```bash
VITE_API_BASE_URL=http://localhost:5000/api
```
### 5. Run the Project in Development Mode
```bash
npm run dev
```
### 5. Build for Production
```bash
npm run build
```
